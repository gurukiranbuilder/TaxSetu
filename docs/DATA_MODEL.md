# Data Model

## Raw Transaction Object

Stored in `localStorage` under key `taxsetu_transactions`. Each transaction is user-entered via the Add Transaction modal.

```js
{
  id:           string,   // e.g. "tx-1712345678901" — generated as 'tx-' + Date.now()
  assetName:    string,   // e.g. "HDFC Bank Ltd"
  assetType:    'equity' | 'debt_mf' | 'gold_unlisted' | 'real_estate',
  buyDate:      string,   // ISO 8601 date "YYYY-MM-DD"
  buyPrice:     number,   // Price per unit (in INR)
  qty:          number,   // Quantity of units
  sellDate:     string,   // ISO 8601 date "YYYY-MM-DD"
  sellPrice:    number,   // Price per unit (in INR)
}
```

### Asset Types

| Value | Meaning | Holding Period for LTCG |
|-------|---------|------------------------|
| `equity` | Listed equity shares (incl. equity-oriented MF) | ≥ 365 days |
| `debt_mf` | Debt-oriented mutual funds | Always STCG (slab rate) |
| `gold_unlisted` | Gold ETFs, unlisted shares | ≥ 730 days |
| `real_estate` | Property (land, building, etc.) | ≥ 730 days |

## Computed / Processed Transaction Fields

Generated by the `processedTransactions` `useMemo` hook. These fields are computed on every render and are NOT persisted.

```js
// Extends the raw transaction with:
{
  // ...all raw fields above...

  // Time-based
  holdingDays:   number,   // days between buyDate and sellDate
  buyFY:         string,   // e.g. "2022-23"
  sellFY:        string,   // e.g. "2025-26"

  // Monetary
  buyCost:       number,   // buyPrice * qty
  saleValue:     number,   // sellPrice * qty
  absoluteGain:  number,   // saleValue - buyCost

  // Tax Classification
  classification: 'STCG' | 'LTCG',
  taxRate:        number,  // decimal (0.125, 0.20, or slab rate)

  // Indexation (real estate only)
  holdsIndexedOption: boolean,   // true if real estate LTCG with buyDate < 2024-07-23
  indexedCost:        number | null,
  indexedGain:        number | null,

  // Computed Tax
  calculatedTax:       number,
  indexationAdvantage: number,   // tax saved by using indexation (positive = savings)
  taxOptimizationNote: string,   // human-readable note explaining the better option
}
```

## CII Table (Cost Inflation Index)

Hardcoded constant `CII_TABLE` in the Babel script block. Used for indexed cost calculation for real estate LTCG.

| Financial Year | Index | Financial Year | Index |
|---------------|-------|---------------|-------|
| 2001-02 | 100 | 2014-15 | 240 |
| 2002-03 | 105 | 2015-16 | 254 |
| 2003-04 | 109 | 2016-17 | 264 |
| 2004-05 | 113 | 2017-18 | 272 |
| 2005-06 | 117 | 2018-19 | 280 |
| 2006-07 | 122 | 2019-20 | 289 |
| 2007-08 | 129 | 2020-21 | 301 |
| 2008-09 | 137 | 2021-22 | 317 |
| 2009-10 | 148 | 2022-23 | 331 |
| 2010-11 | 167 | 2023-24 | 348 |
| 2011-12 | 184 | 2024-25 | 363 |
| 2012-13 | 200 | 2025-26 | 376 |
| 2013-14 | 220 | 2026-27 | 390 |

### Indexed Cost Formula

```
indexedCost = buyCost * (CII[sellFY] / CII[buyFY])

indexedGain = saleValue - indexedCost
```

The app compares:
- **Option A**: `indexedGain * 20%` — Long term at 20% with indexation
- **Option B**: `absoluteGain * 12.5%` — Long term at 12.5% flat (no indexation)

The lower tax amount is selected. This election is available only for real estate assets where `buyDate < 2024-07-23`.

## Persistence Strategy

- **Save**: On every transaction add/delete, the entire `transactions` array is serialized via `JSON.stringify` and written to `localStorage.setItem('taxsetu_transactions', ...)`.
- **Load**: On initial render, the app reads `localStorage.getItem('taxsetu_transactions')`. If no data exists, the `INITIAL_TRANSACTIONS` seed data is used.
- **Clear**: There is no UI for bulk clearing data. Users can clear browser site data manually.
- **Sync**: No cloud sync. All data is local to the browser.
